# 現金管理計算工具 (README 7-2版 ) 

一個專為零售、餐飲等需要頻繁處理現金的場景所設計的智慧計算工具。它不僅能自動計算每日的預留零用金與上繳營收，更提供多種便利的微調功能，讓帳務處理變得輕鬆、準確且高效。

### ✨ 功能亮點 (Features)

- 💰 **智慧計算引擎 (Intelligent Calculation Engine)**
    - 自動計算需移入營收的零頭。
    - 以最優組合計算 `20,000` 元的預留零用金。
    - 精準分配各面額至「預留金」與「上繳營收」區塊。
- ⌨️ **便利輸入模式 (Convenient Input Modes)**
    - **張數快輸**：對於大面額紙鈔，可直接輸入 `0-99` 的張數，系統自動換算為總金額。
    - **袋/捆加總**：可同時輸入散裝金額與整袋/整捆數量，系統會自動加總計算。
- 🔧 **強大的結果微調工具 (Post-Calculation Adjustment)**
    - **預留/上繳交換**：計算結果產生後，可將「預留金」中的特定面額與「上繳營收」中的面額進行等值交換。
    - **零錢收納對換**：專為湊整設計，可將「上繳區」的散裝硬幣與「打包區」的硬幣互換，輕鬆湊成一整袋。
- 🔄 **操作還原與歷史紀錄 (Undo & History)**
    - 所有微調操作都會被記錄下來。
    - 提供「恢復上一步」功能，隨時可以反悔。
    - 可點擊歷史紀錄，直接跳轉回任一時間點的狀態。
- 💾 **狀態自動保存 (Automatic State Persistence)**
    - 採用 `localStorage` 技術，您所有的輸入、計算結果、微調歷史都會自動保存在您的瀏覽器中。
    - 即使重新整理或關閉分頁，回來時進度依然存在。
- 🎨 **高度客製化 (High Customization)**
    - 內建顏色選擇器，讓您可以自訂每個面額的代表顏色，打造個人化的視覺風格。
- 📱 **響應式設計 (Responsive Design)**
    - 介面在桌面、平板與手機上皆有良好的顯示與操作體驗。

### 🧮 核心演算法邏輯 (Core Algorithm Logic)

本工具的計算流程主要分為以下幾個步驟：

1. **資料收集與驗證 (Data Collection & Validation)**
    - 讀取所有輸入框的數值，並將「金額」與「袋/捆」換算的金額加總。
    - 驗證各面額的總金額是否能被該面額整除，確保資料的正確性。
2. **零錢處理 (Small Change Handling)**
    - 計算所有硬幣 (50, 10, 5, 1元) 的總額 `total_coins`。
    - 使用模數運算 `total_coins % 100` 取得不足百元的零頭 `remainder`，此部分將被歸入「營收上繳」。
    - 剩餘可湊成百元的硬幣 `total_coins - remainder` 則優先保留於「預留零用金」。
3. **預留金分配 (Petty Cash Allocation)**
    - 計算目標金額 `20,000` 與已保留硬幣的差額 `needed_cash`。
    - 若 `needed_cash > 0`，則啟動 `findOptimalCombination` 演算法。
    - 此演算法會以**優先使用 100 元**、**再用 500 元輔助**的策略，從現有的紙鈔中找出能剛好填滿差額的最佳組合。若無法完美湊齊，則會盡力湊到最接近的金額。
4. **營收上繳計算 (Revenue Calculation)**
    - 最終的上繳金額為 `全部總金額 - 實際預留零用金總額`。
    - 各面額在上繳區的數量，則為該面額的總數減去被分配至預留金的數量。

### 🚀 如何使用 (How to Use)

1. 在「輸入各面額總金額」區塊，輸入您手邊的現金數量。
    - 可直接輸入總金額（如 `12500`）。
    - 也可輸入袋/捆數（如 `1` 捆 100元）。
    - 對於 1000/500/100 元，可直接輸入張數（如 `15`）。
2. 點擊 **「計算結果」** 按鈕，下方將顯示詳細的分配報告。
3. (可選) 若想調整鈔票或硬幣分配，可展開下方的 **「結果微調工具」** 或 **「收納零錢對換」** 進行操作。
4. (可選) 點擊頂部按鈕，可 **自訂顏色**、**查看包裝資訊** 或 **閱讀說明**。
5. 若要清空，**單擊「清除數值」**；若要徹底重置（包含儲存的資料與顏色），請 **長按「清除數值」5秒**。
